# asp-dot-net-core-web-app-mvc-fast-food-system
**This project is currently under active development. Features and functionality may change**

Fast Food System is a web application built using ASP.NET Core MVC. The system
is designed to manage a fast food restaurant's operations, including menu
management, order processing, and customer management.

The application is intended to run locally and uses SQLite as its database to
store information about products, carts, orders, and customers. It also
includes thermal printer integration for printing receipts and order details.

## Features
- Order management system
- Menu/product management
- Shopping cart functionality
- Customer management
- Thermal receipt printing
- Real-time price updates (AJAX) (partially implemented)

## Technologies Used
- Backend:
    - ASP.NET Core MVC - Web framework
    - C# - Main programming language    
    - Entity Framework Core - ORM for database interactions
- Database:
    - SQLite - Local database for storing application data
- Frontend:
    - Razor Views - For rendering HTML pages
    - JavaScript - Client-side interactivity
    - Fetch API (AJAX) - Asynchronous requests to controller endpoints (partially implemented)
